# AGENT BRIEFING • RL DIECAST (Pré-vendas minigt)

## Resumo do Projeto
A plataforma RL Diecast é um e-commerce completo de miniaturas diecast 1:64 desenvolvido em Next.js 16 (App Router), TypeScript e Tailwind CSS.

## Status Atual
- Todos os arquivos, componentes, rotas e dependências estão instalados neste diretório (`Downloads\Pré-vendas minigt`).
- O banco local em `data/rl_diecast_db.json` possui 66 miniaturas reais importadas com fotos oficiais do Mini GT Brasil.
- O servidor roda com `npm run dev` na porta 3000.
- A paleta de cores adota Obsidiana Profunda (`#080a0f`), Ouro Racing (`#f59e0b`/`#fbbf24`), Esmeralda (`#10b981`) e botões pretos sobre ouro de alto contraste.
- O painel administrativo em `/admin/sincronizacao` possui a aba "Importar por Foto / Blister".
